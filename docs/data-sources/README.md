Снимок OPFF содержит 15 477 записей всех видов животных. Строгий фильтр
cat/dog и проверка контрольной цифры дали 2 593 кандидата, из которых 234
имеют метку США/Канады. Эти числа не означают новых подтверждённых товаров:
нужны сверка с существующими данными, подтверждение точной упаковки,
актуальности, рынка и полной этикетки.

Все кандидаты имеют статус `source_candidate_not_verified`. Их нельзя
автоматически импортировать как `verified` или `source_verified`.
Пример WSDA содержит регистрационные записи, без UPC и ингредиентов.

Сначала прочитайте отчёт и DATA-NOTICE.md. Для подготовки записей research
применяйте действующие инструкции `research/AGENTS.md` и проверку ledger.

Исходный отчёт и ZIP сохранены без изменений. Указание в отчёте об отсутствии
изменений репозитория относится к этапу исследования: эта публикация добавляет
только материалы и ссылки на них, не меняя каталог или приложение.
